# Передача Mystic NFT Drop заказчику

Этот проект запускается на Node.js 20 + Express + SQLite. Production entrypoint: `server.js`. Не используйте старые Python/FastAPI инструкции.

## Что получает заказчик

- Исходный код и доступ к согласованному GitHub-репозиторию.
- Собственный сервис хостинга и HTTPS URL.
- Telegram-бот, настроенный на URL Mini App.
- Инструкцию по переменным окружения и запуску.

## Переменные окружения Render

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота; только Secret в Render |
| `ADMIN_IDS` | Telegram ID администратора, через запятую при нескольких |
| `REQUIRED_CHANNEL` | `@MysticDropNFT` |
| `DEV_MODE` | `false` в production |
| `DB_PATH` | `/var/data/mystic.sqlite3` только после подключения Persistent Disk; иначе оставь текущий путь |

Никогда не добавляйте реальные токены и пароли в GitHub или переписку.

## Развёртывание

1. Build Command: `npm install`.
2. Start Command: `npm start`.
3. Health Check Path: `/api/health`.
4. Добавить переменные окружения выше.
5. Проверить, что бот является администратором канала @MysticDropNFT.
6. Настроить HTTPS URL Mini App через @BotFather.
7. Открыть приложение через Telegram и проверить авторизацию.

## База данных — обязательное предупреждение

На бесплатном Render локальная SQLite не является надёжным постоянным хранилищем и может потеряться при новом deploy/restart. Для production-данных подключите Persistent Disk, смонтируйте его в `/var/data`, затем установите `DB_PATH=/var/data/mystic.sqlite3`. Перед сменой пути сохраните и перенесите текущую базу. Если тариф не поддерживает диск, используйте внешнюю постоянную БД; не обещайте сохранность данных на временном диске.

## Текущий объём реализации

Работают базовая Telegram-авторизация, профиль, MST, задания, проверка подписки, инвентарь, виртуальная рулетка и базовая Mines. Дартс, баскетбол, слоты, кейсы, Upgrade, реальные Telegram Stars invoices, промокоды, рефералы, полноценная админка, заявки на вывод и реальная передача подарков пока не реализованы.

Перед передачей обязательно провести ручные тесты на Telegram-аккаунте заказчика и проверить сохранность базы после рестарта.
