# Mystic NFT Drop

Telegram Mini App на Node.js + Express + SQLite.

## Что уже реализовано

- Авторизация Telegram WebApp по проверенной подписи initData.
- Проверка подписки на обязательный канал @MysticDropNFT.
- Профиль пользователя, баланс виртуальных MST и инвентарь.
- Три режима рулетки: Classic, Premium и Legend; сервер выбирает результат, шансы отображаются в интерфейсе.
- MINES 5×5 с четырьмя минами, серверным состоянием раунда и расчётом множителя.
- Ежедневная награда: 100 MST раз в день; за седьмой день серии — дополнительный бонус 100 MST.
- История последних игровых действий.
- Инструкция покупки Telegram Stars через согласованный внешний бот @Starbuy1bot.
- Адаптивный тёмный дизайн, карточки коллекции, анимации, уведомления и мобильная нижняя навигация.

## Локальный запуск

Требуется Node.js 20+.

1. Выполни npm install.
2. Скопируй .env.example в .env.
3. Для локального демо установи DEV_MODE=true.
4. Запусти npm start.
5. Открой http://localhost:3000.

## Настройка Telegram

1. Создай бота через @BotFather.
2. Добавь бота администратором канала @MysticDropNFT, чтобы проверять подписку.
3. В Render добавь BOT_TOKEN и ADMIN_IDS в Environment.
4. Установи DEV_MODE=false.
5. Укажи HTTPS URL сервиса как адрес Mini App в @BotFather.

Никогда не добавляй токен бота в GitHub и не отправляй его в переписке.

## Render и база данных

- Build: npm install
- Start: npm start
- Health check: /api/health
- Для сохранения SQLite нужен постоянный диск, смонтированный в /var/data. Убедись, что выбранный тариф Render поддерживает persistent disk.

## Важные ограничения

MST и предметы сейчас являются виртуальными внутриигровыми значениями. Покупка Stars в @Starbuy1bot сама по себе не пополняет MST. Автоматическая сверка сторонних покупок, платежи и выдача настоящих Telegram Gifts не реализованы. Не обещай пользователям денежную стоимость, вывод или обмен виртуальных предметов.
