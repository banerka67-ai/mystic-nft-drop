# Mystic NFT Drop

Первая версия Telegram Mini App: коллекционный интерфейс, серверная рулетка с виртуальными предметами, инвентарь и профиль.

## Что сейчас есть
- Главная без отображения баланса.
- Коллекционные карточки в стилизованном объёмном оформлении.
- Серверная рулетка и виртуальный инвентарь.
- Профиль с внутренним балансом и макетом пакетов Telegram Stars.
- Навигация между главной, инвентарём и профилем.

## Важно про Telegram Stars
Экран пакетов Stars пока является только макетом. Реальная оплата не включена: для неё нужно настроить Telegram-бота, создание invoice в валюте XTR, обработчик успешного платежа и серверное начисление. Не считайте нажатие на пакет оплатой — кнопка намеренно отключена до подключения платёжного контура.

Не подключайте платное пополнение к случайной рулетке. Перед запуском платных функций нужно отдельно проверить применимые правила Telegram и законодательство.

## Локальный запуск
1. Установите Python 3.11+.
2. Выполните `pip install -r requirements.txt`.
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`.
4. Для локального просмотра установите `DEV_MODE=true`.
5. Запустите: `uvicorn backend.main:app --reload`.
6. Откройте http://127.0.0.1:8000.

В production отключите DEV_MODE и задайте настоящий BOT_TOKEN.

## Render
Build command: `pip install -r requirements.txt`.
Start command: `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`.
Для SQLite подключите Persistent Disk и задайте `DB_PATH=/var/data/mystic.sqlite3`.

Текущая версия — прототип, а не готовый платёжный продукт.
