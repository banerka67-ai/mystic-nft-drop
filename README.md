# Mystic NFT Drop

Telegram Mini App на Node.js 20 + Express + SQLite. Единственная production-точка входа — `server.js`; старый Python backend удалён, чтобы не было двух несовместимых реализаций.

## Что сейчас реализовано

- Проверка подписи Telegram WebApp initData на сервере и ограничение срока действия данных.
- Профиль, внутренний баланс MST и инвентарь.
- Задание на подписку на @MysticDropNFT с проверкой через Telegram Bot API.
- Ежедневная награда 25 MST: оба API-маршрута используют одну запись claim, повторно получить награду за тот же день нельзя.
- Три виртуальные рулетки с серверным выбором результата, открытыми весами и идемпотентностью по request_id.
- Базовая Mines с серверным расположением мин и атомарными изменениями состояния/баланса.
- Ограничение частоты API-запросов.

## Локальный запуск

Требуется Node.js 20+.

1. Выполни `npm install`.
2. Скопируй `.env.example` в `.env`.
3. Только для локальной разработки установи `DEV_MODE=true`.
4. Запусти `npm start`.
5. Для production обязательно `DEV_MODE=false` и настоящий `BOT_TOKEN` в секретах хостинга.

## Настройка Telegram

1. Добавь бота администратором канала @MysticDropNFT, чтобы он мог проверять участников.
2. В Render добавь `BOT_TOKEN`, `ADMIN_IDS`, `REQUIRED_CHANNEL=@MysticDropNFT`, `DEV_MODE=false`.
3. Укажи HTTPS URL Mini App через @BotFather и настрой кнопку меню/ссылку запуска.
4. Не добавляй токен в GitHub и никогда не отправляй его в чат.

## Render и SQLite — важно

- Build: `npm install`
- Start: `npm start`
- Health check: `/api/health`
- На бесплатном Render файловая система сервиса временная. SQLite в `./data` может быть потеряна при redeploy/restart.
- Для сохранения данных нужен Persistent Disk, смонтированный в `/var/data`, и `DB_PATH=/var/data/mystic.sqlite3`. Проверь доступность диска/тарифа в Render перед включением. Не переключай путь на /var/data, пока диск реально не создан и не смонтирован.
- Для уже работающего приложения перед сменой DB_PATH сначала сделай резервную копию существующей SQLite. Не меняй путь без миграции, иначе приложение увидит пустую базу.

## Что ещё НЕ реализовано

Дартс, баскетбол, слоты, полноценные кейсы и Upgrade, Telegram Stars invoices и подтверждение платежей, промокоды, рефералы, полноценная админ-панель, заявки на вывод и фактическая выдача Telegram Gifts. Текущая админская точка — только сводка API.

MST и предметы сейчас являются виртуальными значениями. Покупка Stars в стороннем боте сама по себе не пополняет MST. Не включай платное пополнение, платную случайную выдачу или вывод до отдельной реализации, проверки правил Telegram и применимых требований закона.

## Проверки перед запуском

1. `npm install` завершается без ошибок.
2. `npm start` запускает Node-сервер.
3. `GET /api/health` возвращает `{"ok":true,...}`.
4. Без Telegram initData защищённые API возвращают 401.
5. Проверить подписку, ежедневный claim, повторный claim, рулетку, повтор request_id, Mines start/reveal/cashout.
6. Проверить сохранность данных после рестарта только после настройки Persistent Disk.
