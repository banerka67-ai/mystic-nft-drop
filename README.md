# Mystic Drop

Telegram Mini App на Node.js + Express + SQLite.

## Основная механика

- Игрок открывает приложение и видит список заданий.
- Подписка на @MysticDropNFT — одноразовое задание с наградой 100 MST. Подписка проверяется через Telegram Bot API.
- Ежедневный вход — награда 25 MST, доступна один раз в сутки.
- Полученные награды зачисляются на внутренний виртуальный баланс MST.
- Инвентарь показывает ранее полученные виртуальные предметы.
- Авторизация Telegram WebApp выполняется по проверенной подписи initData.

## Локальный запуск

Требуется Node.js 20+.

1. Выполни npm install.
2. Скопируй .env.example в .env.
3. Для локального демо установи DEV_MODE=true.
4. Запусти npm start.
5. Открой http://localhost:3000.

## Настройка Telegram

1. Создай бота через @BotFather.
2. Добавь бота администратором канала @MysticDropNFT, чтобы проверять подписку.
3. В Render добавь BOT_TOKEN и ADMIN_IDS в Environment.
4. Установи DEV_MODE=false.
5. Укажи HTTPS URL сервиса как адрес Mini App в @BotFather.

Никогда не добавляй токен бота в GitHub и не отправляй его в переписке.

## Render и база данных

- Build: npm install
- Start: npm start
- Health check: /api/health
- Для сохранения SQLite нужен постоянный диск, смонтированный в /var/data. Убедись, что выбранный тариф Render поддерживает persistent disk.

## Важные ограничения

MST и предметы являются виртуальными внутриигровыми значениями. Покупка Stars в @Starbuy1bot сама по себе не пополняет MST. Автоматическая сверка сторонних покупок, платежи, вывод средств и выдача настоящих Telegram Gifts не реализованы. Не обещай пользователям денежную стоимость или обмен виртуальных предметов.
