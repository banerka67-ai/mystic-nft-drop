# Mystic NFT Drop

Telegram Mini App на Node.js + Express с SQLite.

## Запуск локально

Требуется Node.js 20+.

1. Установи зависимости: `npm install`.
2. Скопируй `.env.example` в `.env`.
3. Для локального демо оставь `DEV_MODE=true`.
4. Запусти: `npm start`.
5. Открой http://localhost:3000.

## Настройка Telegram

1. Создай бота через @BotFather.
2. Добавь бота администратором канала `@MysticDropNFT`, иначе Telegram не даст проверять подписку пользователей.
3. В Render задай `BOT_TOKEN` и `ADMIN_IDS` в Environment.
4. Установи `DEV_MODE=false`.
5. Укажи HTTPS URL сервиса как адрес Mini App через настройки бота в @BotFather.

Токен нельзя добавлять в GitHub или отправлять в переписку.

## Render

- Build: `npm install`
- Start: `npm start`
- Health: `/api/health`

Для SQLite нужен постоянный диск, смонтированный в `/var/data`. Такой диск может требовать платный тариф. Не запускай production без постоянного хранилища, если нужно сохранять баланс и инвентарь.

## Уже реализовано на сервере

- Проверка подписи Telegram WebApp initData.
- Обязательная проверка подписки на `@MysticDropNFT` через Telegram Bot API.
- Создание профиля с балансом 0.
- Три конфигурации рулетки с опубликованными шансами.
- Серверный выбор выигрыша, транзакционное списание баланса и защита повторного запроса.
- API MINES 5×5 с четырьмя минами, серверным состоянием и выводом.
- История и базовая статистика администратора.

## Важный статус

Это промежуточная сборка: frontend ещё нужно связать с новыми экранами трёх рулеток, подписки и MINES. Платежи Telegram Stars и выдача настоящих Telegram Gifts не реализованы. Все баллы и предметы — виртуальные. Не добавляй платные ставки или оплату случайного результата.
